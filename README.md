# Crypto Trade

Crypto Trade is a full-stack crypto trading dashboard with a modern frontend and backend service layer.

## Repository Structure

- `frontend/` - Next.js application UI
- `backend/` - Backend service and API implementation
- `supabase/` - Supabase-related assets and configuration
- `lib/` - Shared local utilities
- `sequence/` - Project assets and supporting files

## Highlights

- Responsive trading dashboard
- Watchlist and leaderboard views
- Trade history and portfolio analytics
- Real-time market visualization components

## Local Development

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Refer to the backend documentation in `backend/API_REFERENCE.md` and `backend/AUTHENTICATION.md` for setup and runtime details.

## Deployment

- Frontend: deploy with Vercel or another Next.js-compatible platform
- Backend: deploy separately on a Java-friendly hosting platform

## Notes

- Environment files are intentionally excluded from version control.
- Build artifacts and dependency folders are ignored for a cleaner repository.
